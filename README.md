# Mis Apps

Dos apps de Android, gratis y para cualquiera. Todo se guarda en tu celular.

| App | Qué hace |
|---|---|
| **Mis Finanzas** | Anota lo que gastas y lo que ganas. Resumen con gráfica de tu saldo, tablas por categoría, varias monedas y exportar a Excel. |
| **Mis Hábitos** | Tus hábitos como misiones de videojuego: ganas XP, subes de nivel y armas rachas. Recordatorio diario opcional. |

## Cómo instalarlas

1. Desde tu celular, entra a **Releases** (a la derecha en esta página) y abre la versión más nueva.
2. Descarga `finanzas.apk` y/o `habitos.apk`.
3. Ábrelo y dale **Instalar**. Si tu celular pregunta, permite "instalar apps de origen desconocido".

La primera vez que abras cada app te pregunta tu nombre y cómo la quieres usar.

## Para quien programa

- Kotlin + Jetpack Compose, sin internet ni cuentas.
- `finanzas/` y `habitos/` son proyectos de Android Studio independientes.
- Cada cambio que se sube a `main` se compila solo con GitHub Actions y se publica en Releases.
